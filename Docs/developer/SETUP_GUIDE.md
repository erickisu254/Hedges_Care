# Hedges Care - Project Setup Guide

This guide provides step-by-step instructions for setting up and running the **Hedges Care** project locally.

## 🚀 Project Overview

Hedges Care is a comprehensive plant care and environmental impact platform. It features:
- **AI Plant Diagnosis:** Scan and identify plant species and health issues.
- **Environmental Dashboard:** Track CO2 sequestration and environmental benefits.
- **Plant Store:** Purchase plants and gardening supplies.
- **NFT Marketplace:** Mint and trade unique plant NFTs with environmental data.
- **Community Forum:** Share knowledge and connect with other plant enthusiasts.
- **Specialist Consultations:** Book sessions with plant care experts.
- **M-Pesa Integration:** Seamless mobile payments for store and consultations.

## ☁️ Supabase Configuration

Hedges Care uses Supabase for Authentication, Database, and Edge Functions.

### 1. Create a New Project
- Log in to [Supabase](https://supabase.com/).
- Create a new project named "Hedges Care".

### 2. Database Setup
- Go to the **SQL Editor** in your Supabase dashboard.
- Create a new query.
- Copy the contents of the `database_schema_queries.txt` file located in the project root.
- Run the query to create all tables, views, and indexes.

### 3. Authentication Setup
- Go to **Authentication** > **Providers**.
- Enable **Email** provider.
- (Optional) Configure other providers as needed.

### 4. Storage Setup (Recommended)
While the project currently uses mock image URLs, you may want to set up buckets for user uploads:
- Create a public bucket named `plant-images`.
- Create a public bucket named `avatars`.
- Update RLS policies to allow authenticated users to upload their own files.

## ⚙️ Environment Variables

1. Create a `.env` file in the root directory:
   ```bash
   cp .env.example .env
   ```

2. Fill in your Supabase credentials:
   - `VITE_SUPABASE_URL`: Your project URL from Settings > API.
   - `VITE_SUPABASE_PUBLISHABLE_KEY`: Your project's `anon` public key from Settings > API.

3. (Optional) Configure other variables:
   - `VITE_NFT_CONTRACT_ADDRESS`: For blockchain features.
   - `VITE_MPESA_PREFIX`: Prefix for M-Pesa transaction IDs.
